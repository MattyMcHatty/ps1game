ORDER OF NINURTA - TRIAL VERSION
Created by @electricreload


WHAT THIS IS
------------
A playable trial version of Order of Ninurta, a survival horror game built
for original PlayStation (PS1) hardware. What you have here is a real disc
image, so it runs on any PS1 emulator (and on a real console, if you burn it).

Files in this folder:

    Order of Ninurta - Trial Version.cue   <- load THIS one
    Order of Ninurta - Trial Version.bin   <- the disc data (keep next to the .cue)
    README.txt                             <- you are here

Keep both files together in the same folder and do not rename either of them,
or the .cue will not be able to find the .bin.


HOW TO PLAY IT
--------------
1. Install a PlayStation emulator. DuckStation is the recommended one and is
   free:  https://www.duckstation.org/

2. DuckStation needs a PS1 BIOS image to run games. It will tell you this the
   first time you start it and will walk you through the setup wizard.

3. In DuckStation, choose  File -> Open File  (or just drag and drop) and pick
   "Order of Ninurta - Trial Version.cue".  Do NOT pick the .bin.

That's it. The game boots straight to the intro.

Any other PS1 emulator will work too (ePSXe, mednafen, RetroArch's Beetle PSX
or SwanStation cores) - in every case, load the .cue file.


CONTROLS  (PlayStation pad; on a keyboard, DuckStation's defaults map the
           d-pad to W/A/S/D and the face buttons to the arrow keys - check
           Settings -> Controllers if you want to see or change them)
--------
  D-PAD UP / DOWN     Walk forward / backward
  D-PAD LEFT / RIGHT  Turn
  L1 / R1             Sidestep left / right
  CROSS  (hold)       Sprint - watch the stamina bar, it locks out if you
                      empty it and won't unlock until it has fully refilled
  CIRCLE (tap)        Interact - doors, items, save points, prompts
  CIRCLE (hold)       Look around freely with the d-pad (you stand still)
  SQUARE              Attack / fire
  TRIANGLE            Switch weapon
  L2     (hold)       Aim the revolver - the d-pad moves the crosshair
  R2                  Switch ammo type
  START               Open the menu (inventory, items, health)

  In menus and puzzles:  d-pad to move, CIRCLE to confirm, CROSS to go back.


SAVING
------
The game saves to a PlayStation memory card, exactly like a real PS1 game.
Find a save point in the world and interact with it (CIRCLE). DuckStation
creates a virtual memory card for you automatically, so saving should just
work - if it says NO MEMORY CARD, check Settings -> Memory Cards and make
sure slot 1 has a card.
